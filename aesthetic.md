# AESTHETIC.md

## Aesthetic

I based my design on inspiration I found through Pinterest with a multitude of graphic design inspiration in a personal Pinterest board. I was drawn to websites that use soft pastel colors, elegant font styles, rounded images, generous white space, and simplistic layouts. 

## CSS Choices

To reflect this style, I chose a light pink color palette with subtle alternating section backgrounds to add visual variety. I paired Cormorant Garamond that I retrieved from Google's large collection of font styles for large headings with Space Mono for navigation and labels to create contrast between elegance and technical design. I also used rounded corners, soft shadows, smooth hover transitions, and generous spacing throughout the site to give it a polished, editorial feel while keeping the content easy to read.

## JavaScript Enhancement

My JavaScript enhancement is a progressive theme picker that allows visitors to choose between Light, Dark, or System mode. The website works correctly without JavaScript by relying on the browser's `prefers-color-scheme` media query. When JavaScript is available, the selected theme is saved using `localStorage` so the user's preference persists across pages and future visits.

## Usability and Accessibility

One design decision I made was ensuring the site remains fully usable when JavaScript is disabled. The theme picker is hidden unless JavaScript loads successfully, preventing users from seeing a control that would not function. I also maintained keyboard-accessible controls, clear focus states, semantic HTML elements, and a responsive layout so the site works well on different screen sizes.

## Reflection

Marshall McLuhan argued that "the medium is the message," meaning the way information is presented influences how it is understood. I wanted my portfolio to communicate creativity, attention to detail, and professionalism before a visitor even reads the content. The soft colors, font styling, spacing, and interactions become part of the message themselves. Rather than simply displaying information about me, the design demonstrates the kind of digital experiences I enjoy creating, reinforcing my identity as a web developer through both the content and the medium used to present it.
